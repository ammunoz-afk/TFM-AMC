# TFM - Análisis y Predicción de la Gentrificación en Barcelona

Este repositorio contiene el código y datasets desarrollados para el Trabajo de Fin de Máster Estudio de los factores de gentrificación de la ciudad de Barcelona.

## Descripción del Proyecto
El objetivo principal de este proyecto es analizar el fenómeno de la gentrificación en los distintos barrios de la ciudad de Barcelona y desarrollar un modelo de Machine Learning capaz de predecir el riesgo futuro de gentrificación. Se ha utilizado información pública extraída de Open Data BCN (alquileres, viviendas de uso turístico, demografía, locales comerciales, etc.).

## Estructura del Repositorio (Contenido)
* **`datasets/`**: Carpeta con los datasets originales y el `master_dataset_bcn.csv` limpio.
* **`notebooks/`**: Contiene los archivos de Jupyter donde se ejecuta el código.
